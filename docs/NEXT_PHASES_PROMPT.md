  helper layers or "while I was in there" fixes. A defect you notice and are not
  asked to fix goes in the Stage 7 report, not in a diff.

  renaming any public function, or running `git commit` / `git push`. List what
  you propose and wait.

  the DD2 golden SNM point and published NMP/TOV values, the CompOSE HS(DD2)

  what you have. `cProfile`/`pstats`/`time.perf_counter` cover the timing work.
- Library code stays as it is unless a stage says otherwise: notebooks and
  benchmarks are written against the public API (`eos_point`, `eos_table`,
  `eos_response`, the `progress` callback), never by instrumenting solver
  internals, and **deep solver code never prints** (§5).
- Non-convergence is a return value, not an exception (§6): a benchmark counts
  non-converged points, it does not crash on them.
- End every stage with a `✅ Stage N complete` line, the verbatim output of the
  commands you ran, and the added-failure count. Then stop for review before the
  next stage. No progress claim without the tool output that backs it.
